# 预算模型参考

> ⚠️ 本文所有数字为**行业经验区间**（2025-2026 年中国大陆口径），用于搭骨架和判断合理性，**不是报价承诺**。正式方案必须用核实到的真实价格回填重算。

---

## 一、机动金（Contingency）

先扣机动金，再分配科目。机动金不是"剩下多少算多少"，是**一开始就切出来不许动**的。

| 场景 | 比例 | 说明 |
|---|---|---|
| 常规室内 1-2 天 | 8% | 默认值 |
| 100 人以上大型活动 | 5% | 规模效应，单项浮动被摊薄 |
| 户外 / 多天气风险 / 远途 | 10% | 雨天备场、改期损失 |
| 出境 / 长线 / 跨境 | 12% | 汇率、签证、境外应急 |
| 含领导出席或对外发布 | +2-3% | 容错要求高，宁可多留 |

机动金用途：加桌、超时费、临时物料、天气备场、突发医疗。**方案里要写明这笔钱留给什么**。

## 六、承载力校验公式

### 6.1 宴会厅面积

```
所需面积 ≈ 桌数 × (12 ~ 15 ㎡)
桌数 = ceil(人数 / 10)
```

- 12 ㎡/桌：紧凑摆法（无大通道）
- 15 ㎡/桌：含主通道、舞台前区、拍摄空间
- **层高 < 4m 不适合搭舞台 + 桁架**；< 3.5m 只能挂背景板
- 舞台按 0.6-1.2 ㎡/人 的观众视角估算视距，最后一排视距不宜超过 30m

### 6.2 客房

```
需要客房数 = ceil(人数 / 2) + ceil(人数 × 单住率 / 2)
```

单住率参考：普通员工 10-15%、管理层 60-80%、销售团队 30-50%、异性别比例失衡时上调。

### 6.3 车辆

```
大巴数 = ceil(人数 / 45)     # 49 座车按实载 45 算
```

### 6.4 餐饮

| 形式 | 面积需求 | 单价参考（一线） |
|---|---|---|
| 圆桌（10 人） | 12-15 ㎡/桌 | ¥80-300/人 |
| 自助餐 | 1.2-1.5 ㎡/人 | ¥80-200/人 |
| 冷餐酒会 | 0.8-1.0 ㎡/人 | ¥100-250/人 |
| 茶歇 | 0.3 ㎡/人 | ¥30-80/人 |

### 6.5 场地停车

```
车位需求 ≈ ceil(自驾人数 / 2.5)
```

## 七、反推路径（当用户只给人均或总额时）

**只给总额**：机动金 → 可支配 → 人均日成本 → 定档位 → 配比 → 科目金额
**只给人均**：人均 × 人数 × 天数 ÷ (1 − 机动金率) = 总额
**只给人数和「想住五星」**：先查目标城市五星均价（间夜），反推住宿科目占比，判断总额至少要多少

**判断"能不能办"的快捷口径**：
```
最低可行总额 ≈ 人数 × 天数 × 该档位下限 × (1 + 机动金率)
```
若用户总额低于此值，直接告知缺口，不要硬做。

## 八、常见超支陷阱（必须写进方案的风险栏）

以下是真实报价单里最容易被漏掉、最后变成"意外超支"的项：

| 陷阱 | 幅度 | 防范 |
|---|---|---|
| **服务费** | 餐费/场租的 10-15% | 报价时必须问"含不含服务费" |
| **开瓶费** | ¥50-200/瓶 | 自带酒水提前确认 |
| 超时费 | ¥500-2000/小时 | 明确进场/撤场时间窗 |
| 加桌 | 单桌全价 | 预留 1-2 桌弹性 |
| 布展进场费 / 押金 | ¥1000-10000 | 桁架、灯光进场常另收 |
| 大巴超时等候 | ¥200-400/小时 | 行程留缓冲，写明等候计费 |
| 电力增容 | ¥2000-8000 | LED 大屏、灯光常需增容 |
| 场地清洁费 | ¥500-3000 | 尤其户外草坪、烧烤 |
| 发票税点 | 3-6% | 需要专票时确认是否含税 |
| 临时加人餐位 | 人均全价 | 报名截止后加人常按全价 |

**建议做法**：报价单逐项核对是否含服务费、税点、进场费；这三项合计常占总价 15-20%。
